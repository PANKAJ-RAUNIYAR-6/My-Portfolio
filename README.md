# Pankaj Rauniyar — Animated Portfolio

A premium dark, responsive React + Vite portfolio inspired by the visual language of modern developer portfolios.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Edit `src/data/portfolio.js` for your profile, skills, projects and links. Major sections are separated into their own React components and CSS files.
